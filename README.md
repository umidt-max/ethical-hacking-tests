2. `index.html` faylini repository ildiziga yuklang va Commit changes bosing.

4. Branch: `main`; Folder: `/(root)`; Save.
5. Bir necha daqiqadan so‘ng sayt: `https://USERNAME.github.io/ethical-hacking-tests/`
